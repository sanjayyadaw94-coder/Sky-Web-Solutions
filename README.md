# Sky Web Solutions - GitHub Pages Ready

This is a ready-to-publish **static reconstruction** of Sky Web Solutions with Home, Services, Work, About, Contact, Privacy, and interactive demo prototypes. It is not a byte-for-byte export of the live AppDeploy Vite/TypeScript project, and visual details may differ.

## Publish
1. Create a public GitHub repository named `sky-web-solutions`.
2. Extract the ZIP and upload **all its contents** (including the hidden `.github` directory) to the repository root on branch `main`.
3. Go to Settings > Pages > Build and deployment > Source: **GitHub Actions**.
4. Check the Actions tab for a successful deployment.
5. Open `https://YOUR-USERNAME.github.io/sky-web-solutions/`.

No npm, Python or PHP server required. The website uses relative file paths so it works under a GitHub repository URL.

## Contact form
The contact form opens the visitor's email application with a prepared enquiry. They must press **Send** in that application. There is no server-side email delivery. WhatsApp and phone links work.

## Portfolio
The shopping cart is a demonstration with no payments; the chatbot is scripted and does not call an AI model.

Never commit SMTP passwords, `.env` files, API keys or secrets to a public repository.
